# Hi, I'm Cameron Ashley

Toronto developer. I run [Ashbi Design](https://ashbi.ca), a small web agency that builds Shopify and WordPress/WooCommerce stores, and I build and ship my own web and mobile apps.

## What I build

- **Client stores and sites:** Shopify themes, WordPress and WooCommerce builds, custom WordPress plugins
- **Web apps:** React and Next.js products with TypeScript, PostgreSQL and real auth, billing and tests
- **Mobile:** offline-first PWAs, wrapped for iOS and Android with Capacitor, plus Expo/React Native
- **AI tools:** LLM features with a human in the loop, bring-your-own-key AI, image generation pipelines
- **Self-hosted infrastructure:** Docker, CI with GitHub Actions, and my own servers in place of SaaS where it makes sense
